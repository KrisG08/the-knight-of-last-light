# Commander completion and save version five

Status: implemented, 2026-11-04.

Commander defeat, Oath Seal and Peaks discovery promote a copied state to schema
five. Existing companion, checkpoint and forest actions preserve newer versions.
Versions one through four remain readable for their implemented progression.
The previously reserved Commander IDs now require discovered Order and version
five; no earlier playable encounter could legitimately create them.

Victory and reward are one action; seal interaction remains separate. The gate
requires seal.oath. VisitPeaks atomically records region.peaks.visited and completed
quest.main.ch03. Validation checks version, discovery, boss/reward/fact consistency,
seal guardian and chapter/gate agreement. Cael is optional throughout main progress.
The existing temp/backup/promotion protocol protects earlier snapshots; unsupported
future versions are still preserved rather than overwritten.

The sanctum and Peaks approach do not add recovery checkpoints. They reuse the
last activated lantern. Companion eligibility excludes the sanctum and includes
the approach. All world barriers/feedback derive from durable campaign facts.
