# Ruined limestone

ruined_limestone.png is an original AI-generated base-color texture created with
the built-in imagegen tool on 2026-11-04 and copied into this project. The user's
reference image supplied mood/direction; it is not embedded or redistributed.
No downloaded third-party material is used. Public asset licensing has not been
selected. The storm sky shader, 3D kit and knight mesh are original authored code.

Generation prompt (built-in tool, no CLI/API workflow):

> Create a square seamless tileable PBR base-color texture for a dark fantasy video game, weathered damp charcoal blue-gray limestone masonry. Irregular old hand-hewn stone blocks with fine cracks, granular stone pores, very subtle desaturated olive moss in narrow recessed joints, restrained variations, medium scale stone blocks, orthographic flat surface filling every edge, uniform diffuse neutral illumination with NO directional lighting, NO shadows, NO perspective, NO vignette, NO text, NO objects. Seamless borders on all four sides, usable repeat texture. High detailed believable gothic ruin material, not an illustration of a building. Original texture.

Only base color is generated; this is not a complete measured PBR/normal/roughness
set. In-engine triplanar mapping supplies consistent scale. Border repetition is
visually usable at the prototype's scale; there is no certified seamless-edge claim.
