# Original burial chamber soundscape

Original deterministic synthesized PCM assets for Last Light, created with
`tools/make_burial_audio.py`. No external recordings, voices or music samples.
Mono PCM16, 22050 Hz. Chamber air: 12 seconds with endpoint fades; seal resonance:
three-second periodic loop; three discrete 0.9-second drip/resonance variations.
Not professional recorded Foley or a finished musical score.
